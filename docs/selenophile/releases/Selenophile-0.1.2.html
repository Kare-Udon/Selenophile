Selenophile 0.1.2

Selenophile 0.1.2 improves Moonraker connection resilience so the menu bar status can recover when a printer starts a job while the app is idle or reconnecting.

Highlights

  • Keep automatic reconnect attempts running with capped 30 second, 1 minute, and 5 minute backoff intervals.
  • Poll Moonraker's current object status while connected so silent printer-state changes are detected within the regular refresh window.
  • Update the UI and widget snapshot when a full status refresh discovers a newly active print.
  • Keep the connection badge in a retrying state while an automatic reconnect is scheduled.
  • Add regression coverage for reconnect backoff, periodic status snapshots, and Moonraker object-query parsing.

Current Limitations

  • This beta still focuses on monitoring. It does not upload G-code, start prints, pause, resume, cancel prints, or modify Klipper configuration.
  • The local release build is ad-hoc signed and is not notarized with a Developer ID certificate.
